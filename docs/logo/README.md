# Rhizo logo

The "o" is a cell that forks: a ring with the weight of the letters, and its
clone budding off. The lettering is Inter Display Bold (SIL Open Font License
1.1) converted to outlines, so the files need no font.

| File | Use |
|---|---|
| `rhizo-logo.svg` | Wordmark on light backgrounds |
| `rhizo-logo-dark.svg` | Wordmark on dark backgrounds |
| `rhizo-mark.svg` | Square icon (avatar, favicon), works down to 16 px |

Colours: ink `#0e2a20`, green `#1f9d6b`, mint `#63d4a0`, paper `#eafaf2`.
The logo is part of the project and shares its MIT license.
